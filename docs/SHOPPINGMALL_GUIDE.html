③ 추천 상품

카테고리 필터

URL의 :category와 상품의 categoryValue가 같은 항목만 남깁니다.

예: /products/category/speaker → categoryValue: "speaker" 상품만 표시

가격대 필터

discountRate를 반영한 할인가로 비교합니다. under10, on10, on20, on30 값이 선택 기준입니다.

정렬

latest는 id 내림차순, low는 낮은 할인가 순, high는 높은 할인가 순입니다.
